# Nine_suns
Mini_game generated by GPT-6 Sol, sandbox game, infinite world generation

# Curse of the Nine Suns

Survive waves of monsters, collect weapons, and find a way to end the curse of the nine suns.

**Controls:** WASD to move, mouse to look, left-click to attack, right-click for a secondary action, Space to jump, R to reload, E for inventory, and 1–9 or the mouse wheel to switch items.
